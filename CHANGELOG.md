# Changelog

## [Unreleased]

- Исправлена iOS-маршрутизация внешних `RULE-SET`: загрузка GitHub-списков и
  общий прокси больше не зависят от устаревших групп `DUREV` / `ALL IN 1`.
- Добавлена проверка целостности iOS/macOS-конфигов: повторные секции и
  дублирующиеся строки теперь блокируют публикацию.
- Добавлена инструкция по обновлению удалённой конфигурации без повторного
  импорта и накопления локальных копий в Shadowrocket.
- Зафиксировано ограничение: дубли, возникающие внутри локальной синхронизации
  или компиляции Shadowrocket, не могут быть исправлены статическим файлом.

## [1.0.2] - 2026-08-24

- Добавлен ежедневный мониторинг удалённых `RULE-SET` в GitHub Actions.
- При сбое сохраняется отчёт и создаётся/обновляется GitHub Issue; после
  восстановления issue закрывается автоматически.
- Добавлен ручной запуск мониторинга через `workflow_dispatch`.
- Добавлены повторные попытки и проверка полноты ответа для защиты от
  кратковременных сетевых сбоев и неполных загрузок.

## [1.0.1] - 2026-08-24

- Добавлена CI-проверка всех удалённых `RULE-SET` из iOS/macOS-конфигов:
  HTTPS, HTTP-статус, содержимое rule-list и защита от HTML-страниц ошибок.

## [1.0.0] - 2026-08-24

- Добавлен самодостаточный failsafe `url-set-main.conf` со встроенными
  локальными и внешними списками.
- В снапшотах failsafe сохранены исходные правила, порядок и `no-resolve`,
  а для каждого внешнего источника записан SHA-256.
- Исправлены регистрозависимые ссылки на Proxy Group в macOS-конфиге.
- Сохранены macOS-специфичные настройки: Spotify через `DIRECT` и узел
  `YOUR-DUREV.COM` в ручной группе.
- Добавлены статическая проверка конфигов и GitHub Actions.
