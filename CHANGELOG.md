# Changelog

## [Unreleased]

- Добавлена отдельная iOS-группа `🪶 Feather`: каталоги и файловые хосты
  по умолчанию идут через проверенный узел `🇫🇮 Финляндия`, GitHub остаётся
  `DIRECT`, а iApps Store получил явное раннее правило `DIRECT`.
- Валидатор отклоняет конфиги, в которые случайно попал полный URI
  прокси-сервера с учётными данными.
- iOS Spotify по умолчанию направлен в финскую авто-группу, а в ручном
  выборе сервера предпочтительной подпиской стала `PREMIUM | ALL IN 1`;
  `YOUR-DUREV.COM` сохранён как запасной вариант.
- iOS-маршрутизация Instagram/Meta напрямую привязана к группе
  `🗺️ Выбор сервера` с предпочтительной подпиской `PREMIUM | ALL IN 1`.
  Для Instagram разрешён QUIC; точечные YouTube-правила сохраняют его откат на TCP/HTTP2.
- GitHub на iOS закреплён через `DIRECT` после подтверждённого теста на устройстве.
- Добавлена отдельная iOS-группа YouTube и встроенные критичные правила для
  YouTube и Instagram/Meta. YouTube использует точную рабочую группу активной
  подписки `🗺️ ВЫБОР СЕРВЕРА`; Instagram покрывает общие Meta ASN `32934` и
  `63293`.
- Полный YouTube `RULE-SET` добавлен в ежедневный мониторинг и встроенный
  failsafe-снапшот.
- iOS-группа `🌍 Общий прокси` выровнена по рабочей схеме macOS с точными
  именами групп активной подписки; сохранено отдельное поведение Spotify.

## [1.0.2] - 2026-08-24

- Добавлен ежедневный мониторинг удалённых `RULE-SET` в GitHub Actions.
- При сбое сохраняется отчёт и создаётся/обновляется GitHub Issue; после
  восстановления issue закрывается автоматически.
- Добавлен ручной запуск мониторинга через `workflow_dispatch`.
- Добавлены повторные попытки и проверка полноты ответа для защиты от
  кратковременных сетевых сбоев и неполных загрузок.

## [1.0.1] - 2026-08-24

- Добавлена CI-проверка всех удалённых `RULE-SET` из iOS/macOS-конфигов:
  HTTPS, HTTP-статус, содержимое rule-list и защита от HTML-страниц ошибок.

## [1.0.0] - 2026-08-24

- Добавлен самодостаточный failsafe `url-set-main.conf` со встроенными
  локальными и внешними списками.
- В снапшотах failsafe сохранены исходные правила, порядок и `no-resolve`,
  а для каждого внешнего источника записан SHA-256.
- Исправлены регистрозависимые ссылки на Proxy Group в macOS-конфиге.
- Сохранены macOS-специфичные настройки: Spotify через `DIRECT` и узел
  `YOUR-DUREV.COM` в ручной группе.
- Добавлены статическая проверка конфигов и GitHub Actions.
