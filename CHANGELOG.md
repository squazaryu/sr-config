# Changelog

## [1.0.1] - 2026-08-24

- Добавлена CI-проверка всех удалённых `RULE-SET` из iOS/macOS-конфигов:
  HTTPS, HTTP-статус, содержимое rule-list и защита от HTML-страниц ошибок.

## [1.0.0] - 2026-08-24

- Добавлен самодостаточный failsafe `url-set-main.conf` со встроенными
  локальными и внешними списками.
- В снапшотах failsafe сохранены исходные правила, порядок и `no-resolve`,
  а для каждого внешнего источника записан SHA-256.
- Исправлены регистрозависимые ссылки на Proxy Group в macOS-конфиге.
- Сохранены macOS-специфичные настройки: Spotify через `DIRECT` и узел
  `YOUR-DUREV.COM` в ручной группе.
- Добавлены статическая проверка конфигов и GitHub Actions.
