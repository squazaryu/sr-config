# sr-config

Конфиги для [Shadowrocket](https://apps.apple.com/app/shadowrocket/id932747118).

## Актуальные профили

| Файл | Назначение |
| --- | --- |
| [url-set-ios.conf](https://raw.githubusercontent.com/squazaryu/sr-config/main/url-set-ios.conf) | Основной iOS: пользовательский экспорт 2026-09-08 19:25:40 с удалённой из AI неиспользуемой подпиской SHD |
| [url-set-macos.conf](https://raw.githubusercontent.com/squazaryu/sr-config/main/url-set-macos.conf) | Группы как в iOS; Spotify через DIRECT, сетевые настройки macOS |
| [url-set-main.conf](https://raw.githubusercontent.com/squazaryu/sr-config/main/url-set-main.conf) | Самодостаточный fallback: встроенные списки, без Proxy Group и внешних RULE-SET |

В iOS сохранён присланный пользователем текст с согласованными правками:
`SHD` исключён из кандидатов AI; `platipomiru.com` и его поддомены направлены
через TELEGRAM, чтобы мини-приложение следовало выбранному маршруту Telegram.
Профиль содержит `update-url` на этот же основной iOS-файл для синхронизации.
В `tun-excluded-routes` добавлено точечное IPv6-исключение `ff02::fb/128`
для локального mDNS/Bonjour, используемого обнаружением устройств Apple.
AI теперь делегирует выбор группе `FINLAND`, а не выбирает узлы напрямую.
FINLAND автоматически выбирает один из пяти финских кандидатов.
Параметры AI: url-test, 600 секунд, tolerance 100 ms, timeout 5 секунд.

FINLAND теперь содержит пять узлов: два прежних и добавленные
`FINLAND 42…-2`, `FINLAND 52…-2` и `🇫🇮 ФИНЛЯНДИЯ | РЕКЛАМА НА ЮТУБУ`.
AI-группа использует только группу FINLAND; общий PROXY в AI не используется.
Spotify на iOS сохраняет шесть кандидатов из предоставленного экспорта, включая ALL VPN.
Имена внешних записей должны совпадать с именами на устройстве; страна выхода
не подтверждается ни названием, ни успешной проверкой gstatic.

Apple/iCloud и известные российские домены закреплены ранними DIRECT-правилами.
Для почты IMAP/SMTP маршруты закреплены явно: iCloud Mail, Яндекс и Mail.ru
идут через DIRECT; Gmail/Googlemail также используют DIRECT.
Вход Google (`accounts.google.com` и `accounts.google.ru`) закреплён за
финской AI-политикой.
Правила доменов действуют независимо от портов 993, 465 и 587; отдельные
широкие DST-PORT-правила для почты не используются.
Каталоги Feather направлены через PROXY, поскольку прямой путь к части
репозиториев отвечает с большой задержкой или не отвечает.
Instagram и Meta вынесены в отдельную группу INSTAGRAM с прокси-пулом по
умолчанию, по аналогии с YouTube.
Основные и вспомогательные адреса ChatGPT, включая LiveKit, Statsig,
Feature Gates и Segment, направлены в AI; для четырёх основных
доменов сохранена точечная блокировка QUIC. Другие сервисы, DNS/IPv6,
GEOIP и FINAL сохранены как в пользовательском экспорте.

Импортировать основной iOS по URL, активировать его, выбрать маршрутизацию
«Конфигурация» и переподключить VPN. Проверить выбранные записи AI на устройстве.
В macOS используется та же схема групп с исключением Spotify DIRECT.
Самодостаточный fallback сохраняет собственную схему маршрутизации.

## Google AI Studio и Google-вход (2026-10-12)

Оба активных профиля содержат ранний встроенный блок Google AI: AI Studio,
Gemini, Gemini API, Google-вход/OAuth и API-хосты, обнаруженные в публичной
странице AI Studio. В обоих профилях путь — `AI → FINLAND`.
Исключение `accounts.google.ru`
стоит перед общим `ru,DIRECT`; `accounts.google.com` больше не использует
обычный выбранный PROXY на iOS.

В локальном журнале Mac от 2026-10-11 `accounts.google.ru` выбирал DIRECT,
а `aistudio.google.com` и `alkalimakersuite-pa.clients6.google.com` использовали
ALL VPN Швеция. Новые правила устраняют это различие политик. SMTP/IMAP Gmail
на iOS сохраняют DIRECT; поисковые, YouTube и прочие общие Google-правила
сохраняют свои политики. Общий `ai-services.list` и самодостаточный fallback
не изменены.

Для проверки обновите соответствующий профиль, активируйте режим
«Конфигурация», переподключите VPN и откройте AI Studio в новой вкладке.
Проверьте выбранный узел обеих AI-групп: url-test измеряет задержку,
а фактическую страну выхода определяет провайдер. Успешную работу аккаунта
нужно подтвердить на устройстве. Google дополнительно проверяет регион,
возраст и подтверждение возраста:
[официальные условия доступа](https://ai.google.dev/gemini-api/docs/available-regions).

## Почта на macOS (2026-10-13)

`gmail.com`, `googlemail.com` и `mail.me.com` направляются через DIRECT для
IMAP/SMTP. Google web/OAuth остаётся в финской AI-группе; этот маршрут не
меняет почтовые соединения на iOS.

## Общие группы iOS/macOS (2026-10-14)

На обеих платформах одинаковые группы, их порядок, кандидаты, вложенные
зависимости и значения по умолчанию. Единственное исключение —
`SPOTIFY = select,DIRECT,policy-select-name=DIRECT` на macOS.
`FINLAND` содержит те же пять узлов, `SERVERS` и `AUTO` скопированы из iOS.
YouTube, Instagram/Meta и Telegram Mini App используют соответствующие
`YOUTUBE`, `INSTAGRAM` и `TELEGRAM`-маршруты из iOS. Транспортные UDP/QUIC-правила
этим переносом не менялись.

При обновлении macOS-профиля имена узлов (`DUREV`, `FINLAND 42/52 …-2`,
`⚡️ULTRA` и AUTO-узлы) должны совпадать с записями в Shadowrocket на Mac.
Валидатор сравнивает группы обоих профилей и учитывает только исключение
SPOTIFY DIRECT. Сетевые настройки `[General]` macOS сохранены.

## Проверка

GitHub Actions отключены вручную; автоматические проверки перед merge сейчас
не выполняются. Локальные проверки:

```sh
python3 -m unittest discover -s tools -p 'test_*.py'
python3 tools/validate_configs.py
python3 tools/check_remote_sources.py
```

Тесты проверяют основной iOS, сохранность архива и независимых профилей.
Проверка источников обращается только к актуальным iOS/macOS; архив не является
набором действующих профилей. Проверки не эмулируют Shadowrocket на iPhone.

python3 tools/build_failsafe.py --check отдельно сравнивает резервный снимок
с текущими внешними источниками. Fallback обновлён: рекламный reject.txt
теперь содержит 8760 правил, включая восемь новых доменов.

Локальные списки хранятся в `lists/`. Их изменение влияет на подключающие
их профили, но не обновляет уже встроенные снимки fallback автоматически.
