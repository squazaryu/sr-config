# sr-config

Конфиги для [Shadowrocket](https://apps.apple.com/app/shadowrocket/id932747118).

## Основной iOS с группами и отдельный fallback

| Файл | Назначение |
|---|---|
| [url-set-ios.conf](https://raw.githubusercontent.com/squazaryu/sr-config/main/url-set-ios.conf) | Основной профиль: принятый пользователем N01 с управляемыми группами |
| [url-set-main.conf](https://raw.githubusercontent.com/squazaryu/sr-config/main/url-set-main.conf) | Самодостаточный fallback: полностью расписанные правила, без групп и внешних RULE-SET |

Основной iOS перенесён из `url-set-ios-names-test.conf` после сообщения
пользователя о работающем тестовом варианте. От N01 отличаются только
начальный комментарий о назначении файла и собственная ссылка update-url.
Все 135 правил, 18 RULE-SET, порядок, DNS/TUN/IPv6, параметры matching,
QUIC-настройки, имена серверов и параметры выбора сохранены без изменений.

- Локальные группы: `AI`, `SPOTIFY`, `WEATHER`, `TELEGRAM`, `DEFAULT`,
  `YOUTUBE`, `ADS`, `FINLAND`, `SERVERS`, `AUTO`.
- AI использует `AI → FINLAND → финский узел`. FINLAND остаётся исходным
  url-test с семью именованными кандидатами, `interval=300`, `tolerance=50`,
  `timeout=5` и gstatic URL. Состав не менялся и не очищался при переносе.
- Spotify и каталоги Feather также используют FINLAND; погода, Telegram,
  DEFAULT и FINAL по умолчанию следуют PROXY. YouTube/Meta используют маршруты N01.
- Российский DIRECT/GEOIP, Apple и GitHub сохраняются как в N01.

Fallback `url-set-main.conf` уже совпадал с прежним полностью расписанным
iOS-файлом, кроме своей ссылки обновления, поэтому оставлен побайтово прежним.
Его AI-правила по-прежнему указывают на конкретную запись «🇫🇮 Финляндия»,
не на FINLAND и не на ALL VPN; эта запись должна существовать в приложении.
Это отдельный резервный профиль для выбора пользователем, а не группа типа
fallback и не автоматическое переключение при сбое основного профиля.

У основного iOS, fallback и тестового N01 независимые update-url. Сам N01,
S01 и macOS не изменены. Основной iOS и fallback намеренно имеют разные
механизмы маршрутизации; не выравнивать их при последующих правках автоматически.

После публикации обновить **основной url-set-ios.conf**, активировать его,
выбрать маршрутизацию «Конфигурация» и полностью переподключить VPN.
Проверить цепочку `AI → FINLAND`, ChatGPT сразу и после паузы. Сохранённый
тестовый N01 и отдельный fallback остаются доступны для сравнения/возврата.

39 статических тестов защищают точность переноса и неизменность остальных
профилей; они не эмулируют Shadowrocket или региональные ответы OpenAI.
Причинная роль Location не доказана. Разрешения приложения, подписки и
серверные ключи при этом переносе не менялись.

## Полный iOS-тест с короткими именами — N01

[url-set-ios-names-test.conf](https://raw.githubusercontent.com/squazaryu/sr-config/main/url-set-ios-names-test.conf)
— сохранённый эталон на основе прежнего iOS (PR #42). Его настройки перенесены
в основной iOS; сам тестовый файл и S01 оставлены без изменений.

Названия групп без эмодзи, в одном ASCII-регистре:
`AI`, `SPOTIFY`, `WEATHER`, `TELEGRAM`, `DEFAULT`, `YOUTUBE`, `ADS`,
`FINLAND`, `SERVERS`, `AUTO`.
Объявления, ссылки между группами, policy-select-name и ссылки из правил
совпадают посимвольно. Имена серверов и подписок не переименованы: их эмодзи,
регистр и пробелы сохранены для сопоставления с записями в приложении.

В отличие от упрощённого S01, N01 сохраняет **все 135 правил и 18 RULE-SET**
прежнего профиля, включая порядок, параметры pre/extended-matching и no-resolve.
Типы групп, кандидаты, выбранные политики по умолчанию и вложенность сохранены.
Сетевые настройки General/DNS/TUN/GEOIP также не менялись. Исключения — собственный
update-url теста, локальное переименование групп и комментарии.

AI использует `AI → FINLAND → финский узел`: FINLAND остаётся url-test с теми же
семью серверами и прежними параметрами 300/50/5 и gstatic URL. DEFAULT и FINAL
остаются через PROXY; российский DIRECT, Apple и GitHub сохранены.

Это проверка **именования в целом**, а не только регистра букв. Новые имена
могут изменить использование сохранённого выбора групп; успешный тест не будет
сам по себе доказательством, что именно капс вызывал региональный отказ.
Проверки сопоставляют преобразование текста и структуру, а не эмулируют Shadowrocket.

Для проверки импортировать N01 новым отдельным профилем, выбрать маршрутизацию
«Конфигурация», оставить прежний основной сервер и переподключить VPN.
В группе AI должен быть выбран FINLAND, а FINLAND должен автоматически выбирать
среди семи финских кандидатов. Проверить ChatGPT сразу и после паузы.
У N01 собственный update-url, не заменяющий S01 или основной iOS.

## Отдельный упрощённый тест iOS — S01

[url-set-ios-simple-test.conf](https://raw.githubusercontent.com/squazaryu/sr-config/main/url-set-ios-simple-test.conf)
— отдельный эксперимент. Основные iOS/macOS/failsafe этим тестом не изменены.
Импортировать как **новый отдельный профиль**, не вместо сохранённого рабочего.
Его update-url указывает только на этот тестовый файл, не на основной iOS.

| Трафик | Маршрут теста |
|---|---|
| Домены AI, Spotify, каталоги Feather | `TEST-FI`: автоматическая финская группа |
| YouTube и Instagram/Meta | `TEST-MEDIA`: по умолчанию `PREMIUM \| ALL IN 1` |
| Telegram, погода, общий и неизвестный трафик | `PROXY`: сервер главного экрана |
| Российские сервисы, Apple/watchOS, GitHub и локальная сеть | Сохранённые DIRECT-правила |
| Наши четыре домена трекеров | `TEST-ADS`: REJECT, вручную можно выбрать DIRECT |

`TEST-FI` — **url-test, а не ручной select**. Семь кандидатов и все параметры
скопированы из исходной `Финляндия (авто)` без изменений: `interval=300`,
`tolerance=50`, `timeout=5`, gstatic generate_204; первоначальная policy —
`PROXY TG | ФИНЛЯНДИЯ`. AI-правила ведут прямо в TEST-FI, без внешней AI select-группы.
PROXY/DIRECT не входят в кандидаты TEST-FI. Новые ASCII-имена трёх групп не
используют старые сохранённые имена; вложений между группами самого файла нет.
Имена серверов/подписок по-прежнему должны существовать в Shadowrocket.

Упрощение относительно прежней iOS-версии PR #42:

- 290 встроенных правил; конфиг не загружает внешние RULE-SET.
- Все десять небольших списков `lists/` встроены снимком базы `b21fcca`.
  Для пересекающихся записей сохранена более ранняя специальная политика:
  например, GitHub — DIRECT, YouTube/Meta — TEST-MEDIA, а не общий PROXY.
- Telegram дополнен уже существующим snapshot blackmatrix7 из failsafe,
  включая ASN и IPv6. Дубликаты убраны; IPv6 записаны как IP-CIDR6.
- Для YouTube сохранён встроенный критичный набор, для Meta — домены/ASN/IP;
  точечные YouTube QUIC-правила также сохранены, QUIC Meta не блокируется.
- Нет сторонних community/refilter-списков, общего списка портов Discord,
  полного внешнего списка YouTube и массового reject-списка.
- Нет pre-matching/extended-matching: используются обычные встроенные правила
  в явном порядке; AI/медиа идут до общих правил и GEOIP.

Это сохранение основной логики сервисов, **не точная копия покрытия всех
сторонних списков**. Для неизвестного домена с российским IP может сработать
GEOIP,DIRECT вместо прежнего исключения из refilter. Рекламная фильтрация слабее,
а редкие YouTube/Discord-адреса из исключённых списков могут пойти через FINAL.
Небольшие списки встроены снимком и не обновляются самостоятельно.

General/DNS/TUN/IPv6 сохранены как в F08. Обычный `GEOIP,RU,DIRECT`, Apple/GitHub
DIRECT и три точечных исключения F08 тоже оставлены. Тест не проверяет гипотезу
полного отключения GEOIP или изменения DNS. Изменено сразу несколько аспектов
обработки правил: успех S01 сузит область поиска, но не докажет виновность одного
конкретного правила. URL-тест проверяет доступность gstatic, а не разрешённый
регион OpenAI; название финского узла не гарантирует фактический выходной IP.

Проверка на iPhone:

1. Импортировать S01 отдельно и выбрать маршрутизацию «Конфигурация».
2. На главном экране оставить прежний рабочий финский сервер, чтобы не менять
   одновременно путь Telegram/погоды/FINAL; TEST-FI сам выбирает финский узел для AI.
3. Полностью переподключить VPN и проверить ChatGPT сразу и после паузы,
   затем российский сервис, Telegram и одно видео YouTube.
4. При региональном отказе сохранить свежий журнал этого сеанса. Не переключать
   группы по кругу: в журнале должен быть виден конкретный кандидат TEST-FI.
   Для возврата достаточно активировать прежний профиль; он не изменялся.

Статические тесты S01 запускаются существующим CI. Они проверяют структуру,
группы, CIDR, встроенные списки и порядок доменных правил, но не эмулируют
Shadowrocket, GEOIP-базу, фактический прокси-выход или ответы ChatGPT.

## Полностью расписанный fallback

`url-set-main.conf` — самодостаточный базовый rule-конфиг и failsafe. Все
локальные и внешние списки встроены в него снапшотом; внешние источники и их
SHA-256 указаны рядом с соответствующими блоками. Поэтому он не зависит от
доступности сторонних URL списков во время работы Shadowrocket.

Ссылка для подписки (Add Config → URL):

```
https://raw.githubusercontent.com/squazaryu/sr-config/main/url-set-main.conf
```

## macOS: независимый конфиг с группами

[url-set-macos.conf](https://raw.githubusercontent.com/squazaryu/sr-config/main/url-set-macos.conf)
не изменён переносом N01 в основной iOS. В нём остаются группы AI, Spotify, погоды, Telegram,
общего прокси и рекламы, финский url-test и ручной выбор сервера.
Spotify намеренно использует DIRECT, YOUR-DUREV.COM остаётся в ручной группе.
Имена внешних серверов и подписок должны совпадать с записями в Shadowrocket.

## Списки доменов (`lists/`)

Основной iOS и macOS подключают отдельные .list-файлы через RULE-SET.
В fallback main списки встроены снимком; редактирование list само по себе
не обновляет встроенный текст. Следующая таблица показывает политику списка,
с учётом более ранних специальных правил конкретного профиля.

| Файл | Политика | Содержимое |
|---|---|---|
| `lists/ai-services.list` | AI (iOS) / 🤖 AI-сервисы (macOS) | OpenAI/ChatGPT, Claude, Gemini, Genspark, Manus |
| `lists/spotify.list` | SPOTIFY (iOS) / 🎧 Spotify (macOS) | Spotify |
| `lists/weather.list` | WEATHER (iOS) / 🌤️ Погода (macOS) | CARROT Weather / Foreca |
| `lists/telegram-domains.list` | TELEGRAM (iOS) / ✈️ Telegram (macOS) | доп. домены Telegram |
| `lists/telegram-ips.list` | TELEGRAM (iOS) / ✈️ Telegram (macOS) | доп. IP-диапазоны Telegram |
| `lists/ru-direct-domains.list` | DIRECT | Госуслуги, Яндекс, соцсети РФ, маркетплейсы, банки, связь, карты |
| `lists/ru-direct-ips.list` | DIRECT | IP госуслуг, mos.ru, Я.Маркета |
| `lists/apple.list` | DIRECT | Apple/iCloud/App Store |
| `lists/general-proxy.list` | DEFAULT (iOS) / 🌍 Общий прокси (macOS) | Google/YouTube, Meta, Discord, GitHub, прочее |
| `lists/trackers.list` | ADS (iOS) / 🛡️ Реклама и трекеры (macOS) | доп. анти-трекинг домены |

Локальные/loopback-правила, MTProto, RU-зоны (`.ru/.su/рф/...`), GEOIP и
`FINAL` остались прямо в конфиге — они короткие и критичные, вынос не
даёт выгоды.

Резервный `url-set-main.conf` содержит локальные правила и снапшоты
внешних списков, но без `RULE-SET`, которые требуют сетевой загрузки во время
работы. Существующий сборщик обновляет только fallback main. В этом переносе
снапшоты сохранены без изменений; использовать режим --check. Следующее
обновление fallback требует отдельной проверки его правил и эталонного хеша.

Критичные серверы каталога и загрузки watchOS, а также проверки сертификатов
Apple/DigiCert продублированы непосредственно в трёх конфигах с политикой
`DIRECT` и расположены до внешних списков. Это сохраняет проверку обновления
работоспособной даже при временной недоступности `apple.list`.

Проверка ролей профилей, точности переноса N01 и актуальности снапшотов без записи файлов:

```
python3 -m unittest discover -s tools -p 'test_*.py' -v
python3 tools/validate_configs.py
python3 tools/build_failsafe.py --check
```

Проверка запускается автоматически в GitHub Actions для каждого push и pull
request. CI также проверяет доступность всех удалённых `RULE-SET` основного
iOS и macOS. Проверить это локально можно командой:

```
python3 tools/check_remote_sources.py
```

Кроме проверки при изменениях, workflow
`.github/workflows/monitor-remote-sources.yml` запускается ежедневно в 09:00 по
Москве и доступен для ручного запуска через GitHub Actions. При недоступности
источников он сохраняет отчёт и создаёт/обновляет GitHub Issue; после
восстановления issue закрывается автоматически. Для email/push-уведомлений
нужно включить Watch/Actions notifications для репозитория.

Первый версионированный baseline — `v1.0.0`; для быстрого отката можно
использовать, например,
`https://raw.githubusercontent.com/squazaryu/sr-config/v1.0.0/url-set-ios.conf`.
