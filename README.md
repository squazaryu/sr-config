# sr-config

Конфиги для [Shadowrocket](https://apps.apple.com/app/shadowrocket/id932747118).

## Отдельный упрощённый тест iOS — S01

[url-set-ios-simple-test.conf](https://raw.githubusercontent.com/squazaryu/sr-config/main/url-set-ios-simple-test.conf)
— отдельный эксперимент. Основные iOS/macOS/failsafe этим тестом не изменены.
Импортировать как **новый отдельный профиль**, не вместо сохранённого рабочего.
Его update-url указывает только на этот тестовый файл, не на основной iOS.

| Трафик | Маршрут теста |
|---|---|
| Домены AI, Spotify, каталоги Feather | `TEST-FI`: автоматическая финская группа |
| YouTube и Instagram/Meta | `TEST-MEDIA`: по умолчанию `PREMIUM \| ALL IN 1` |
| Telegram, погода, общий и неизвестный трафик | `PROXY`: сервер главного экрана |
| Российские сервисы, Apple/watchOS, GitHub и локальная сеть | Сохранённые DIRECT-правила |
| Наши четыре домена трекеров | `TEST-ADS`: REJECT, вручную можно выбрать DIRECT |

`TEST-FI` — **url-test, а не ручной select**. Семь кандидатов и все параметры
скопированы из исходной `Финляндия (авто)` без изменений: `interval=300`,
`tolerance=50`, `timeout=5`, gstatic generate_204; первоначальная policy —
`PROXY TG | ФИНЛЯНДИЯ`. AI-правила ведут прямо в TEST-FI, без внешней AI select-группы.
PROXY/DIRECT не входят в кандидаты TEST-FI. Новые ASCII-имена трёх групп не
используют старые сохранённые имена; вложений между группами самого файла нет.
Имена серверов/подписок по-прежнему должны существовать в Shadowrocket.

Упрощение относительно основной версии:

- 290 встроенных правил; конфиг не загружает внешние RULE-SET.
- Все десять небольших списков `lists/` встроены снимком базы `b21fcca`.
  Для пересекающихся записей сохранена более ранняя специальная политика:
  например, GitHub — DIRECT, YouTube/Meta — TEST-MEDIA, а не общий PROXY.
- Telegram дополнен уже существующим snapshot blackmatrix7 из failsafe,
  включая ASN и IPv6. Дубликаты убраны; IPv6 записаны как IP-CIDR6.
- Для YouTube сохранён встроенный критичный набор, для Meta — домены/ASN/IP;
  точечные YouTube QUIC-правила также сохранены, QUIC Meta не блокируется.
- Нет сторонних community/refilter-списков, общего списка портов Discord,
  полного внешнего списка YouTube и массового reject-списка.
- Нет pre-matching/extended-matching: используются обычные встроенные правила
  в явном порядке; AI/медиа идут до общих правил и GEOIP.

Это сохранение основной логики сервисов, **не точная копия покрытия всех
сторонних списков**. Для неизвестного домена с российским IP может сработать
GEOIP,DIRECT вместо прежнего исключения из refilter. Рекламная фильтрация слабее,
а редкие YouTube/Discord-адреса из исключённых списков могут пойти через FINAL.
Небольшие списки встроены снимком и не обновляются самостоятельно.

General/DNS/TUN/IPv6 сохранены как в F08. Обычный `GEOIP,RU,DIRECT`, Apple/GitHub
DIRECT и три точечных исключения F08 тоже оставлены. Тест не проверяет гипотезу
полного отключения GEOIP или изменения DNS. Изменено сразу несколько аспектов
обработки правил: успех S01 сузит область поиска, но не докажет виновность одного
конкретного правила. URL-тест проверяет доступность gstatic, а не разрешённый
регион OpenAI; название финского узла не гарантирует фактический выходной IP.

Проверка на iPhone:

1. Импортировать S01 отдельно и выбрать маршрутизацию «Конфигурация».
2. На главном экране оставить прежний рабочий финский сервер, чтобы не менять
   одновременно путь Telegram/погоды/FINAL; TEST-FI сам выбирает финский узел для AI.
3. Полностью переподключить VPN и проверить ChatGPT сразу и после паузы,
   затем российский сервис, Telegram и одно видео YouTube.
4. При региональном отказе сохранить свежий журнал этого сеанса. Не переключать
   группы по кругу: в журнале должен быть виден конкретный кандидат TEST-FI.
   Для возврата достаточно активировать прежний профиль; он не изменялся.

Статические тесты S01 запускаются существующим CI. Они проверяют структуру,
группы, CIDR, встроенные списки и порядок доменных правил, но не эмулируют
Shadowrocket, GEOIP-базу, фактический прокси-выход или ответы ChatGPT.

## Основной конфиг

`url-set-main.conf` — самодостаточный базовый rule-конфиг и failsafe. Все
локальные и внешние списки встроены в него снапшотом; внешние источники и их
SHA-256 указаны рядом с соответствующими блоками. Поэтому он не зависит от
доступности сторонних URL списков во время работы Shadowrocket.

Ссылка для подписки (Add Config → URL):

```
https://raw.githubusercontent.com/squazaryu/sr-config/main/url-set-main.conf
```

## Конфиги с группами (iOS / macOS)

`url-set-ios.conf` и `url-set-macos.conf` — конфиги с **Proxy Group**: трафик
по категориям (AI-сервисы, Spotify, Погода, Telegram, общий прокси,
блокировка рекламы) можно
переключать одним тапом в приложении — без правки правил. Есть группа
ручного выбора сервера и группа авто-выбора самого быстрого (по пингу).
Начальные политики различаются между iOS, macOS и базовым failsafe;
актуальные iOS-пути и ограничения описаны ниже.

Для сервисов с автоматическим выбором сохранена отдельная группа
«🇫🇮 Финляндия (авто)», которая сама выбирает между
доступными финскими нодами по пингу. На iOS она задана как политика Spotify
по умолчанию. В ручной группе выбора сервера предпочтительная iOS-подписка —
`PREMIUM | ALL IN 1`; `YOUR-DUREV.COM` остаётся доступной как запасной.
Устаревшие policy `🇫🇮 ФИНЛЯНДИЯ`, `🇫🇮 ФИНЛЯНДИЯ 2` и `FINLAND 🇫🇮` исключены
из iOS auto-группы и защищены от случайного возврата статической проверкой.

Файлы независимые (два отдельных импорта), чтобы группы на телефоне и на
Mac переключались раздельно.

На iOS `🌍 Общий прокси` и завершающее правило `FINAL` используют встроенный
`PROXY`, как в рабочем F08: это сервер, выбранный на главном экране.
Для подтверждённого финского пути нужно оставить там `ALL VPN | Финляндия`.
При смене главного сервера этот выход также изменится. Это отличие от macOS
и прежнего iOS-пути через `PREMIUM | ALL IN 1`.
Spotify остаётся через финскую auto-группу; macOS Spotify — через `DIRECT`.

На iOS встроенные правила Instagram/Meta напрямую используют группу
`🗺️ Выбор сервера`, без ещё одной вложенной Instagram-группы. По умолчанию
эта группа выбирает `PREMIUM | ALL IN 1`, но её можно переключить вручную.

На iOS Telegram использует группу `✈️ Telegram v2`: по умолчанию она следует
за встроенной политикой `PROXY`, то есть за конкретным сервером, выбранным на
главном экране Shadowrocket. `🗺️ Выбор сервера`, `🇫🇮 Финляндия (авто)` и
`🚀 Авто (пинг)` доступны как ручные запасные варианты. Новое имя группы
сбрасывает сохранённый выбор предыдущей Telegram-политики. macOS сохраняет
независимую группу `✈️ Telegram` и прежний порядок выбора.

На iOS погода использует отдельную группу `🌤️ Погода v2` с `PROXY` по
умолчанию. `DIRECT` и `🇫🇮 Финляндия (авто)` остаются ручными вариантами;
macOS сохраняет прежнюю независимую погодную группу через Финляндию.

На iOS `🤖 AI-сервисы (Финляндия)` типа `select` содержит единственную
`🇫🇮 ФИНЛЯНДИЯ (АВТО)`, с ней же в `policy-select-name`. Строка сохранена
точно из рабочего пользовательского экспорта от 2026-09-04 14:05:27.
Домены AI-списка направляются в существующую финскую auto-группу; прямой
привязки к одному ALL VPN, дополнительного fallback или нового AI URL-теста нет.

Основа — диагностический F08: пользователь подтвердил работу ChatGPT в сеансе
4 сентября 2026, 13:15–13:22. В журнале ChatGPT, Sentry и RevenueCat использовали
`ALL VPN | Финляндия`; почта Яндекса одновременно шла через `GEOIP,RU,DIRECT`.
PR #40 заменил этот механизм явной привязкой по имени ALL VPN; после обновления
региональный отказ вернулся. При контрольном возврате к исходному F08 на том же
выбранном сервере пользователь снова подтвердил работу. PR #41 восстановил
активные строки исходного F08 и добавил ссылку обновления. Затем пользователь
вернул только AI на финскую auto-группу и подтвердил работу этого варианта;
сейчас сохранена именно эта правка. Остальная схема F08 не изменена. Причина
прежнего регионального отказа не считается доказанной.

Все российские DIRECT-правила и обычный `GEOIP,RU,DIRECT` сохранены. Из F08
также перенесены три ранних точечных исключения для `shdnetwork.website`,
`sub.alvsub.cc`, `your-durev.com` через `PROXY`, без изменения относительно F08.
Активная подписка ALL VPN использует `sub.alvsub.cc`; два других домена
относятся к неиспользуемым подпискам. Правила не добавляют и не активируют их.
Обращений к этим трём доменам в успешном журнале нет: их необходимость и
причина прежней региональной ошибки не доказаны. Не расширять исключения
без нового свидетельства. `tools/fixtures/ios-f08.conf` — тестовый эталон,
не профиль для установки. Тест разрешает относительно этого эталона только
строку update-url и точную пользовательскую замену AI-группы на Финляндию (авто).
Комментарии не учитываются; остальные активные строки должны совпадать.

Сама общая финская auto-группа не изменена: семь разрешённых
policy, включая FASTCON; `interval=300`, `tolerance=50`, `timeout=5`, gstatic.
Три старых коротких имени не возвращаются. macOS и самодостаточный failsafe
этим изменением не затронуты.

После обновления существующего iOS-файла выбери маршрутизацию «Конфигурация»,
на главном экране оставь тот же проверенный `ALL VPN | Финляндия`, полностью
переподключи VPN и перезапусти ChatGPT. В группах должны отображаться
`AI-сервисы (Финляндия) → Финляндия (авто)` и `Общий прокси → PROXY`.
Проверь отправку сообщений сразу и после паузы, а также российские сервисы.
При отказе зафиксируй новый журнал и верни сохранённый рабочий F08 на том же
сервере и сети; не меняй несколько настроек одновременно.

Финский маршрут задан для доменов AI-списка, а не обязательно для всех запросов
приложения. Общий прокси и FINAL по-прежнему следуют главному серверу, поэтому
запросы вне AI-списка могут зависеть от него. Не считать PROXY или название узла
гарантией геолокации и регионального доступа. Тесты и CI проверяют файл, а не
успешность всех будущих запросов к ChatGPT через любой узел финской auto-группы.

На iOS GitHub-источники Feather сохраняют подтверждённую маршрутизацию
`DIRECT`, а iApps Store (`rejail.ru`) закреплён через ранний `DIRECT` до
внешних списков. Подтверждённые сравнительными логами каталоги UTM, FastSign,
AppTesters, Hot Tub и StikDebug напрямую используют существующую группу
`🇫🇮 Финляндия (авто)` без отдельной промежуточной Feather-группы.

QUIC на iOS разрешён, чтобы Instagram мог обновлять Explore/CDN через UDP/443.
Для критичных YouTube-доменов QUIC блокируется отдельными логическими правилами,
чтобы сохранить откат на TCP/HTTP2. Требуется Shadowrocket 2.2.87 или новее.

На macOS Spotify намеренно направляется через `DIRECT`, а `YOUR-DUREV.COM`
остаётся доступной в ручной группе выбора сервера. Это платформенные настройки,
их не следует удалять при синхронизации конфигов.

Ссылки для подписки:

```
iOS:   https://raw.githubusercontent.com/squazaryu/sr-config/main/url-set-ios.conf
macOS: https://raw.githubusercontent.com/squazaryu/sr-config/main/url-set-macos.conf
```

Финская авто-группа содержит имена узлов и групп из подписки; если после
импорта какой-то пункт не резолвится, открой сервер в Shadowrocket и проверь
точное написание имени.

## Списки доменов (`lists/`)

Правила в `url-set-ios.conf` / `url-set-macos.conf` не перечисляют домены
внутри себя — они подключают отдельные `.list`-файлы через `RULE-SET`,
как это уже делалось для сторонних списков (Telegram, community/refilter
и т.п.). Так конфиг остаётся компактным, а списки доменов можно
редактировать отдельно, без изменения самого конфига:

| Файл | Политика | Содержимое |
|---|---|---|
| `lists/ai-services.list` | 🤖 AI-сервисы (Финляндия) (iOS) / 🤖 AI-сервисы (macOS) | OpenAI/ChatGPT, Claude, Gemini, Genspark, Manus |
| `lists/spotify.list` | 🎧 Spotify | Spotify |
| `lists/weather.list` | 🌤️ Погода v2 (iOS) / 🌤️ Погода (macOS) | CARROT Weather / Foreca |
| `lists/telegram-domains.list` | ✈️ Telegram v2 (iOS) / ✈️ Telegram (macOS) | доп. домены Telegram |
| `lists/telegram-ips.list` | ✈️ Telegram v2 (iOS) / ✈️ Telegram (macOS) | доп. IP-диапазоны Telegram |
| `lists/ru-direct-domains.list` | DIRECT | Госуслуги, Яндекс, соцсети РФ, маркетплейсы, банки, связь, карты |
| `lists/ru-direct-ips.list` | DIRECT | IP госуслуг, mos.ru, Я.Маркета |
| `lists/apple.list` | DIRECT | Apple/iCloud/App Store |
| `lists/general-proxy.list` | 🌍 Общий прокси | Google/YouTube, Meta, Discord, GitHub, прочее |
| `lists/trackers.list` | 🛡️ Реклама и трекеры | доп. анти-трекинг домены |

Локальные/loopback-правила, MTProto, RU-зоны (`.ru/.su/рф/...`), GEOIP и
`FINAL` остались прямо в конфиге — они короткие и критичные, вынос не
даёт выгоды.

Основной `url-set-main.conf` содержит те же локальные правила и снапшоты
внешних списков, но без `RULE-SET`, которые требуют сетевой загрузки во время
работы. При изменении внешних источников обновляй snapshot командами:

Критичные серверы каталога и загрузки watchOS, а также проверки сертификатов
Apple/DigiCert продублированы непосредственно в трёх конфигах с политикой
`DIRECT` и расположены до внешних списков. Это сохраняет проверку обновления
работоспособной даже при временной недоступности `apple.list`.

```
python3 tools/build_failsafe.py
python3 tools/validate_configs.py
```

Для проверки актуальности без записи файла:

```
python3 tools/build_failsafe.py --check
```

Проверка запускается автоматически в GitHub Actions для каждого push и pull
request. CI также проверяет доступность всех удалённых `RULE-SET` из iOS/macOS
конфигов. Проверить это локально можно командой:

```
python3 tools/check_remote_sources.py
```

Кроме проверки при изменениях, workflow
`.github/workflows/monitor-remote-sources.yml` запускается ежедневно в 09:00 по
Москве и доступен для ручного запуска через GitHub Actions. При недоступности
источников он сохраняет отчёт и создаёт/обновляет GitHub Issue; после
восстановления issue закрывается автоматически. Для email/push-уведомлений
нужно включить Watch/Actions notifications для репозитория.

Первый версионированный baseline — `v1.0.0`; для быстрого отката можно
использовать, например,
`https://raw.githubusercontent.com/squazaryu/sr-config/v1.0.0/url-set-ios.conf`.
